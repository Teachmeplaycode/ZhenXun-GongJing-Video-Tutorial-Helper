# 反诈风险线索（Issue #3，仍为 Draft）

`GET /api/link-jobs/{job_id}/antifraud` 从已取得的转写、画面文字、抽样关键帧生成带时间点的规则与引流线索，并使用项目已配置的模型做上下文综合判断。二维码通过 OpenCV 实际解码；相同二维码重复出镜只保留一次。模型输出必须引用输入中已有的证据 ID；模型未配置、失败、超时或返回无效证据时，保留规则线索并明确标为未完成模型判断。

报告不依赖未合并的 factcheck 分支。逐条说法遵循 #2 约定的 `claim/original_text`、`timestamp/evidence`、`verdict/risk`、`reason/sources/status` 字段。规则匹配或模型判断均不等于权威核实，条目保持 `unverified`。联系方式或二维码本身不被认定为诈骗；前端分别展示规则评分和模型可用时的综合风险。

- 尚未以 5–10 条真实公开反诈视频做冒烟验收。
- 尚无人收集并确认诈骗类/正常类各几十条视频与标签，因此未测量 85% 识别率、10% 误报率，不声称达到这两个指标。
- 二维码只覆盖已采样的最多 64 帧；检测不到不等于完整视频没有二维码。

合并前应补足机构核验并完成人工视频验收。不要把反诈宣传片中引用的诈骗话术当成宣传诈骗；目前模型会结合原文判断上下文，但仍需真实视频评测。
