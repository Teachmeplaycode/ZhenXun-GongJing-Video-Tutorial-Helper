## 功能
1. 首页工具栏增加“设置”，保持现有样式，适配窄屏、键盘与 Escape 关闭
2. 设置面板：模型与 API、平台账号、本地运行说明
3. 支持当前实际代码已使用的问答模型 provider（OpenAI 兼容服务与 Ollama）、base URL、模型名、API Key，以及 Tavily、OpenAlex 等实际已有服务，不能做只有 UI 无接线的配置
4. API Key 不回显原文，显示已配置状态，空白保留原密钥，单独明确清除；关闭后清掉未提交输入；不能存在 localStorage、URL、日志或 git
5. 复用现有 AccountsDrawer/AccountCard 的 B 站、元宝/视频号、小红书扫码、手动 Cookie、状态、取消和退出逻辑，统一从设置访问，保持既有导入失败的账号跳转和公有演示个人账号绑定兼容
6. 本地配置保存于 gitignored 本地配置文件，原子写入、UTF-8，沿用明确的环境变量优先规则，展示有效值和配置来源（密钥仅状态）
7. 保存后新请求实际使用新模型，不能只是修改文件却继续使用 app.get_llm 的旧缓存，且不能关闭正在生成中的客户端；外部环境覆盖时要明确告诉用户
8. 设置读写接口仅用于本地部署，公有演示必须关闭或拒绝修改服务器全局配置，跨站请求拒绝，loopback 绑定与 Host/Origin 校验
9. Windows 提供双击 start.cmd + PowerShell 或跨平台 Python 启动器，支持空格和中文目录，不要求 bash，检查 Python/uv/Node/ffmpeg，清楚报告安装步骤、端口占用，等待后端健康再打开浏览器，Ctrl+C 只清理自己启动的进程
10. 首次没有 API Key 也能打开首页进入设置，ASR/OCR 在 Windows 使用 faster-whisper/RapidOCR，依赖按平台选择，不引入 macOS 的 Vision/MLX
11. 保留 macOS/Linux 现有启动方式，不改线上部署默认行为，不迁移本机 .env、Cookie、数据库、模型权重
