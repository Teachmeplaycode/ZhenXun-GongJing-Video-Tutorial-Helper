一、视觉方向
参考 Bilibili 视频 https://www.bilibili.com/video/BV1pEa66NEGA/ 中 A 方案的背景 3D 薄片雕塑。提取其参数化结构、连续扭转、米白哑光材质和柔光层次，并将这种视觉语言应用于视频理解工作台。
整体采用精密科研工具的气质：暖灰白底、近黑文字、细线网格、简洁的技术标签、局部黑色信息块。荧光黄绿表示活动或成功，橙色表示需要处理的问题。所有装饰性细节保持克制。

中文使用清晰的黑体；标题使用无衬线字体；时间戳、运行编号和参数使用等宽字体。正文不小于 14px，次要元数据不小于 12px。标题、正文、元数据具有明确尺度差异。主要操作使用紧凑的深色按钮，组件采用直角或 2–6px 小圆角。
使用等宽字体或加宽的无衬线字体（Univers Extended / Helvet）

避免大圆角卡片瀑布、彩虹渐变、霓虹光晕、厚重投影、随意堆叠的伪代码与无法解释的随机编号。

二、标志性效果
用 Three.js 实现原创的参数化薄片雕塑：沿连续的空间曲线排列约 300–500 个细薄片，形成环形、带状、有明显起伏和前后遮挡的结构。局部截面持续扭转，使模型缓慢展开与收拢，整体同时进行缓慢的多轴旋转。方向变化应连续，避免薄片法线突然翻转。
使用米白或浅灰哑光材质、大面积柔光、柔和灰色阴影、正交或长焦透视相机。通过薄片间的窄缝、边缘明暗与交叠制造精密感。鼠标移动可触发非常轻微的相机视差。用 InstancedMesh 或 shader 提高性能；降低设备负载时减少片数；页面不可见时暂停；支持 prefers-reduced-motion 和 WebGL 失败时的静态替代。
首次进入或尚未导入视频时，在主区域显著展示雕塑，旁边放视频导入与任务输入。导入视频后，模型开始整体同时进行快速的多轴旋转。方向变化应连续，然后颜色可以适当反转为其对应的深色，模型可隐喻视频帧沿时间轴排列。

三、界面结构
用户将按照固定流程来使用我们的应用
完成一步后进入下一步
中间首页一个和页面有一点小padding的大线框容器，然后里面放置我们的这个动态薄片雕塑，然后找个适当的位置提供用户上传视频的入口
视频上传后进行一个遮罩盖住我们这个动态雕塑，然后当完全遮罩后，上传过程中有加载动画，就是参考/Users/linyi/project/videoComprehensive里面的等高线模型
我们做一个从等高线最底部绘制整个地形的动画效果，循环动画
知道上传结束后,遮罩丝滑退场,然后动态雕塑开始播放，会适当翻转为深色
然后这个过程上面显示正在进行视频关键帧抓取以及时间轴等关键数据获取
完成后就会出现按钮进入下一步
下一步点击之后线框容器遮罩刷新新的界面
类似聊天对话框
用户在右侧,AI在左侧,头像框都用圆角矩形
头像图片后续补上（暂用纯色块代替）
然后原先动态雕塑按照顺序排好，出现在线框容器下方，类似时间轴
然后时间轴上的对应薄片hover后可以适当向上带点偏移，适当让周边的薄片也带点偏移让其还是整体还是曲线，然后对应hover的薄片可以显示对应关键帧的图以及相应信息
然后用户可以选中其中几个薄片作为附件带入提问，用户如果未划分范围就默认理解整个视频
