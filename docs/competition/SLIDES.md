## 第 2 页：问题与痛点

**标题**：视频教程的"卡点"问题

**要点**：
- 教程里说"点击设置"——哪个设置？
- 教程里说"等 3 分钟"——从哪一秒开始？
- 教程里说"这个方法有效"——有证据吗？
- 本演示检验回答是否能连回原片，竞品能力不在本轮比较范围

**图示**：[用户提问 → AI 回答 → 结束]（无证据链）

---

## 第 3 页：解决方案

**标题**：帧见——结论—证据—时间—回看原片

**流程**：
```
意图识别 → 取证工具和技能 → 回答 → 引用校验 → 回看原片
```

**要点**：
- 每条结论标注证据类型（原声/画面文字/时间点）
- 有可定位的时间引用且原片可用时，可点击跳回；缺失时如实提示
- 视频里没有的内容，明确说"没有提到"

## 第 4 页：意图识别

**标题**：不同问题，不同回答方式

**要点**：
- 教程问题：看帧、读转写、慢放
- 核查问题：联网查资料、检索论文
- 反诈问题：调用反诈技能
- 决策模块过滤搜索结果、拦截网页注入

**出处**：PR #28 `feat/intent`

## 第 5 页：取证工具

**标题**：让 agent 长出视频理解能力

**工具列表**：
| 工具 | 作用 |
|------|------|
| `search_transcript` | 搜转写关键词 |
| `read_transcript` | 读某时间段转写 |
| `view_frames` | 现场抽 1-6 帧 |
| `replay` | 慢放复看（16 帧/秒） |
| `measure_motion` | 镜头运动、运动强度、周期、热力图 |

**出处**：`backend/modules/agent/tools.py`

## 第 6 页：评测数字

**标题**：MotionBench 细粒度动作理解评测

**历史实验文档报告值；本轮未重跑模型评测**：

| 配置 | 测试集（600 题） | 验证集（360 题） | token |
|------|-----------------|-----------------|-------|
| A48（48 帧） | 56.0% | — | 10.7k |
| C（手写校准） | **62.5%** | 61.7% | 12.2k |
| E（学到校准） | **63.3%** | 65.0% | 12.9k |

**注意**：62.5% 与 63.3% 分属不同配置；C/E差异未达显著，不能声称E显著优于C。token列为测试集平均输入token。

**复现命令**：
```bash
cd backend && uv run python scripts/bench.py --config E --n 100
```

## 第 7 页：引用校验

**标题**：回答完成前逐条校验引用

**要点**：
- 结论 → 证据类型 → 时间 → 点击回看
- 展示证据校验与原片可用状态；引用可定位不等于事实正确，以UI实际标签为准
- 模型乱码或空回复会被重试（PR #24）

**图示**：[回答气泡 → 证据标签 → 时间跳转 → 原片片段]

---

## 第 8 页：回看原片

**标题**：从回答跳回原片

**要点**：
- 点击时间戳，视频跳转到对应位置
- 慢放播放器（0.25× / 0.5× / 原速）
- 逐帧翻、胶片条、跳回原视频
- 本地上传保留原片时可回放；主动删除原片后只保留缓存证据，平台回放还受网络和权限限制

**出处**：PR #25 `feat/playback`
